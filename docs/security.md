# 安全说明

## 凭据去向

- 游戏服 VerifyToken / API Key、SMTP 凭据、Steam Key、TOTP Secret 以 AES-256-GCM 加密保存在**你自己服务器**的数据目录里，主密钥为 `master.key` 或 `PFC_MASTER_KEY`。
- 这些凭据只会由后端发送到你配置的 SLDataAPI 服务器（Steam Key 发往 Steam Web API，SMTP 凭据发往你配置的邮件服务器）；浏览器不持有游戏服凭据，作者和任何第三方都接触不到。
- 平台不含遥测或统计上报。

## 应用安全边界

- 密码：scrypt + 随机盐 + 恒时比较
- 敏感配置：AES-256-GCM
- 会话：随机 Token，服务端存储，7 天过期
- 权限：后端强制 `admin/user/guest`
- 用户数据：按用户 ID 隔离
- 私网代理：非管理员拒绝私网目标

## 文件权限

`master.key` 必须保持 `600`，数据目录建议 `700` 并由运行平台的专用用户持有。迁移和恢复后重新检查属主、权限和 JSON 可解析性。

## 部署建议

- 通过 HTTPS 反向代理对外提供服务，并设置 `PFC_PUBLIC_URL`
- 首次启动后立即注册首个账户（自动成为管理员）；在此之前不要把端口暴露到公网，或先只监听 `127.0.0.1`
- 为管理员账户启用 2FA
- 不要把数据目录、`.env`、证书私钥提交到仓库
